# Источники пакета объяснений

## Церковнославянский текст

Елизаветинская Библия (1751/1757), оригинальная орфография, общественное достояние.

- Файл: `CSlElizabeth-CS.json` (в git не хранится, 12 МБ).
- Откуда: https://raw.githubusercontent.com/asdf-a11/ChurchSlavonicBibleInUtf8/main/CSlElizabeth-CS.json
- SHA-256: `de40ffb4457c2d61f1330eff631496091ad69046efa08781326cdf733e28dc1e`

Скачать: `curl -sL -o tools/commentary/sources/CSlElizabeth-CS.json <ссылка выше>`.

Известные пробелы: в этом файле повреждена Псалтирь (одна «глава» из 22 обрывков), поэтому для Псалмов церковнославянского текста нет — нужен другой источник. Ещё ~150 стихов в других книгах расходятся по нумерации и не попадают в пакет.
