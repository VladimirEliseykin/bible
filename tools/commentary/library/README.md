## Описание источников

### Лопухин, «Толковая Библия» (общественное достояние)
- Мф: `https://azbyka.ru/otechnik/Lopuhin/tolkovaja_biblija_51/<глава 1–28>`; индексная страница `.../tolkovaja_biblija_51/` содержит введение к Евангелию (о Матфее) и оглавление.
- Сир: Лопухин (в продолжении «Толковой Библии») – отдельная книга `https://azbyka.ru/otechnik/Lopuhin/tolkovanie-na-knigu-premudrosti-iisusa-syna-sirahova/<глава 1–51>`; индекс содержит «Предисловие» (введение). Текст стихов + краткое пояснение по группам стихов. Номер тома `tolkovaja_biblija_NN` для Сираха не работает (в таком виде его нет), нужен именно этот slug.
- Номера глав совпадают с синодальными. Для глав больше последней (`/29`, `/52`) сайт отдаёт индекс, а не ошибку – не выходить за пределы.

### Экзегет.ру, толкования по стихам
- Схема: `https://ekzeget.ru/bible/evangelie-ot-matfea/glava-<N>/stih-<V>/` и `https://ekzeget.ru/bible/kniga-premudrosti-iisusa-syna-sirahova/glava-<N>/stih-<V>/` (slug Матфея именно `evangelie-ot-matfea`, а не `...matfeya`).
- Проверено на Мф 5:3 (79 блоков «Толкование на группу стихов») и Сир 2:1 (Агафангел (Соловьёв), Ириней (Орда), ACCS и др.). Страница стиха содержит толкования к группе стихов, куда входит данный стих, поэтому одно и то же толкование встречается на нескольких страницах.
- Нумерация Сираха на ekzeget совпала с синодальной во всех 51 главах (максимальный номер стиха и число ссылок на стихи сверены с `bible.db`: всего 1523 стиха). Для Мф тоже сверено: все 28 глав, 1071 стих, расхождений нет.
- ВАЖНО: одна страница стиха весит около 0,8 МБ по сети (2,4 МБ распакованных: в HTML встроен JSON со всей Библией). Скрейпер должен вырезать только блоки толкований. Ответ сервера медленный (около 5–10 с на страницу): 2594 страницы последовательно займут 4–7 часов. Не делать параллельных запросов; пауза 1 с. Страницы главы целиком (`.../glava-N/`) толкований не содержат.
- Часть толкований на ekzeget – современные переводы (ACCS, Иероним, Хроматий и др.): только пересказ и короткие цитаты.

## Оговорки по нумерации
- Сир: синодальная нумерация (1523 стиха) совпадает с ekzeget и Лопухиным (по главам и стихам). Рождественский опирается на еврейский текст и греческую нумерацию, разбивает главы по смыслу (гл. 1:1–20, 1:22–30; 5:1–6:4 и т. п.), некоторые границы глав сдвинуты. 
- Мф: синодальная нумерация совпадает с ekzeget (28 глав, 1071 стих).
- Беседы Златоуста идут не по главам: одна беседа может охватывать части двух-трёх глав, поэтому в `urls.tsv` она повторена в каждой главе. Аналогично у Гладкова и «Троицких листков».
