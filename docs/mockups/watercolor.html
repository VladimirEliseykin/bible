Как смотрятся акварели

Временные образцы — картинки, которые ты сохранил: светлая тёплая акварель, много неба и света. Подставлены по группам книг, пока ты генерируешь свои.

1Главная

Карусель артов (листается сама, можно свайпать), ниже «Продолжить чтение».

2Полки с обложками

Как библиотека: у каждой книги обложка-арт, группы листаются вбок. Самый «красивый», но книги не видны все сразу.

Изображения — твои примеры из Pinterest, только для внутреннего предпросмотра.
