# Библия для Android v1 — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Офлайн-приложение для чтения Синодальной Библии (77 книг) на Android: главная с каруселью артов, оглавление «полки с обложками», экран чтения с артом главы и разделёнными стихами.

**Architecture:** Gradle-проект из двух модулей. `:tools:dbgen` — консольная Kotlin/JVM-программа, которая при сборке превращает USFM-файлы Синодального перевода в SQLite-базу (`bible.db`) с FTS4-индексом по основам слов. `:app` — Android-приложение на Jetpack Compose; при первом запуске копирует базу из assets во внутреннюю память и читает её через `android.database.sqlite` (только чтение), позицию и настройки хранит в DataStore.

**Tech Stack:** Kotlin 2.2.20, AGP 8.13.1, Gradle 8.14.3 (wrapper), Jetpack Compose (BOM 2025.09.01), Material 3, Navigation Compose 2.9.5, DataStore Preferences 1.1.7, kotlinx-coroutines 1.10.2; для генератора — sqlite-jdbc 3.50.3.0, Lucene analysis-common 9.12.2 (Snowball RussianStemmer); тесты — JUnit 4.13.2, kotlinx-coroutines-test, Compose UI Test.

**Spec:** `docs/superpowers/specs/2026-10-12-bible-app-v1-design.md`

## Global Constraints

- minSdk 26, targetSdk 36, compileSdk 36. Только Android, только светлая тема.
- Никакой сети: в манифесте нет `android.permission.INTERNET`.
- Текст: Синодальный перевод из `bibleonline/rst`, каталог `usfm/rst78`, коммит `2de3062388a2c067bc602399bda7149eec918ceb` (Public Domain). Молитва Манассии (`15-prayerofmanasseh.usfm`) в v1 не включается.
- 77 книг в православном порядке; `verse.id = book_id * 1_000_000 + chapter * 1_000 + verse`.
- Шрифты: Literata (текст), Golos Text (интерфейс), лицензия OFL, файлы в `res/font`, суммарно ≤ 700 КБ.
- Палитра: фон `#FFFFFF`, текст `#1F242C`, приглушённый `#6B7482`, золото `#B08A3E`, линии `#EBE5D8`.
- Размер: release APK ≤ 6 МБ.
- Версии зависимостей фиксированы в `gradle/libs.versions.toml`. Если какая-то версия не резолвится, взять ближайшую стабильную (проверить через context7) и зафиксировать её же — без диапазонов и `+`.
- Каждая git/bash-команда выполняется отдельно, без `&&`. Коммиты: `{type}: {description}` на английском, с подписью `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Не использовать python-скрипты.
- Картинки из `docs/mockups/art/` (Pinterest) в приложение не попадают никогда.

## Review Focus

1. **Границы Библии и книг при свайпе** — назад с Бытия 1 и вперёд с Откровения 22 ничего не делают; из последней главы книги свайп ведёт в первую главу следующей книги, из первой главы — в последнюю главу предыдущей. Тесты: Task 6.
2. **Сохранённая позиция указывает в никуда** (после обновления базы или порчи DataStore: книга 99, глава 0, стих 500) — открываем ближайшую существующую главу с начала, не падаем. Тесты: Task 6.
3. **Процесс убит системой посреди чтения** — при следующем запуске открывается та же глава на том же стихе. Позиция пишется при каждой остановке прокрутки, а не в `onDestroy`. Тест: Task 11.
4. **Максимальный размер шрифта + длинная глава** (Пс 118, 176 стихов; системный fontScale 2.0) — текст переносится, ничего не обрезается, прокрутка плавная. Тест: Task 11.
5. **Нет места при первой распаковке базы** — показывается экран «Недостаточно памяти…» с кнопкой «Повторить», недокопированный файл не остаётся и не считается готовой базой. Тесты: Task 5.

import org.junit.Assert.assertEquals
import org.junit.Assert.assertTrue
import org.junit.Test

class BookCatalogTest {
    private val books = BookCatalog.books

    @Test fun has77BooksWithSequentialIds() {
        assertEquals(77, books.size)
        assertEquals((1..77).toList(), books.map { it.id })
    }

    @Test fun testamentSplitIs50And27() {
        assertEquals(50, books.count { it.testament == Testament.OLD })
        assertEquals(27, books.count { it.testament == Testament.NEW })
    }

    @Test fun deuterocanonicalBooksAreEleven() {
        assertEquals(
            listOf("2Езд", "Тов", "Иудф", "Прем", "Сир", "ПосИер", "Вар", "1Мак", "2Мак", "3Мак", "3Езд"),
            books.filter { it.deuterocanonical }.map { it.abbr },
        )
    }

    @Test fun orthodoxOrderAroundNehemiah() {
        val abbrs = books.map { it.abbr }
        val i = abbrs.indexOf("Неем")
        assertEquals(listOf("Неем", "2Езд", "Тов", "Иудф", "Есф"), abbrs.subList(i, i + 5))
    }

    @Test fun knownChapterCounts() {
        val byAbbr = books.associateBy { it.abbr }
        assertEquals(50, byAbbr.getValue("Быт").chapters)
        assertEquals(151, byAbbr.getValue("Пс").chapters)

        assertEquals(14, byAbbr.getValue("Дан").chapters)
        assertEquals(22, byAbbr.getValue("Откр").chapters)
        assertEquals(1360, books.sumOf { it.chapters })
    }

    @Test fun abbrsAndFilesAreUnique() {
        assertEquals(77, books.map { it.abbr }.toSet().size)
        assertEquals(77, books.map { it.file }.toSet().size)

```kotlin
package bible.dbgen

data class ParsedVerse(val chapter: Int, val verse: Int, val text: String)

object UsfmParser {
    private val footnote = Regex("""\\f\s.*?\\f\*""")
    private val altVerse = Regex("""\\va\s.*?\\va\*""")
    private val inlineMarker = Regex("""\\(add|wj|em)\*?""")
    private val paragraphMarker = Regex("""^\\(p|m)\b""")
    private val chapterLine = Regex("""^\\c\s+(\d+)""")
    private val verseStart = Regex("""\\v\s+(\d+)\s*""")
    private val spaces = Regex("""\s+""")

    fun parse(usfm: String): List<ParsedVerse> {
        val result = mutableListOf<ParsedVerse>()
        var chapter = 0
        var verse = 0
        val buffer = StringBuilder()

        fun flush() {
            if (chapter > 0 && verse > 0) {
                val text = buffer.toString().replace(spaces, " ").trim()
                result += ParsedVerse(chapter, verse, text)
            }
            buffer.clear()
        }

        for (raw in usfm.lines()) {
            val line = raw.trim()
            chapterLine.find(line)?.let {
                flush(); verse = 0
                chapter = it.groupValues[1].toInt()
                return@let
            }
            if (line.startsWith("\\c")) continue
            if (chapter == 0) continue
            var body = line.replace(footnote, "").replace(altVerse, "").replace(paragraphMarker, "")
            if (body.isBlank() && !line.startsWith("\\p") && !line.startsWith("\\m")) continue
            var cursor = 0
            for (m in verseStart.findAll(body)) {
                buffer.append(' ').append(body, cursor, m.range.first)
                flush()
                verse = m.groupValues[1].toInt()
                cursor = m.range.last + 1
            }
            body = body.substring(cursor)
            buffer.append(' ').append(body)
        }
        flush()
        return result.map { it.copy(text = it.text.replace(inlineMarker, "").replace(spaces, " ").trim()) }
    }
}
```
Примечание: `flush()` внутри цикла `\v` для первого стиха главы вызывается при `verse == 0` и ничего не пишет — это правильно, текст до первого `\v` в главе отбрасывается. Строки-заголовки (`\mt`, `\id`, `\rem`) встречаются только до первого `\c` и отбрасываются условием `chapter == 0`.

package bible.dbgen

import org.tartarus.snowball.ext.RussianStemmer

object TextNormalizer {
    private val word = Regex("""[а-я]+(?:-[а-я]+)*""")

    fun stems(text: String): String {
        val stemmer = RussianStemmer()
        val lower = text.lowercase().replace('ё', 'е')
        return word.findAll(lower).joinToString(" ") { m ->
            stemmer.setCurrent(m.value)
            stemmer.stem()
            stemmer.current
        }
    }
}

        val chapters = list.map { it.chapter }.toSortedSet()
        if (chapters.toList() != (1..b.chapters).toList()) {
            errors += "${b.abbr}: ожидалось глав ${b.chapters}, найдено ${chapters.size} ($chapters)"
        }
        list.filter { it.text.isBlank() }.forEach { errors += "${b.abbr} ${it.chapter}:${it.verse}: пустой стих" }
        list.groupBy { it.chapter to it.verse }.filterValues { it.size > 1 }.keys
            .forEach { (c, v) -> errors += "${b.abbr} $c:$v: повтор номера стиха" }
        list.filter { it.verse > 999 || it.chapter > 999 }.forEach { errors += "${b.abbr} ${it.chapter}:${it.verse}: номер вне диапазона id" }
    }
    return errors
}

fun writeDatabase(out: File, books: List<BookInfo>, verses: Map<Int, List<ParsedVerse>>) {
    out.parentFile?.mkdirs()
    out.delete()
    DriverManager.getConnection("jdbc:sqlite:${out.path}").use { c ->
        c.autoCommit = false
        c.createStatement().use { s ->
            s.executeUpdate("CREATE TABLE book(id INTEGER PRIMARY KEY, testament INTEGER NOT NULL, grp TEXT NOT NULL, title TEXT NOT NULL, short_title TEXT NOT NULL, abbr TEXT NOT NULL, chapters INTEGER NOT NULL, deutero INTEGER NOT NULL)")
            s.executeUpdate("CREATE TABLE verse(id INTEGER PRIMARY KEY, book_id INTEGER NOT NULL, chapter INTEGER NOT NULL, verse INTEGER NOT NULL, text TEXT NOT NULL)")
            s.executeUpdate("CREATE INDEX verse_chapter ON verse(book_id, chapter, verse)")
            s.executeUpdate("CREATE VIRTUAL TABLE verse_fts USING fts4(content=\"\", stem)")
        }
        c.prepareStatement("INSERT INTO book VALUES(?,?,?,?,?,?,?,?)").use { p ->
            for (b in books) {
                p.setInt(1, b.id); p.setInt(2, if (b.testament == Testament.OLD) 0 else 1); p.setString(3, b.group.name)
                p.setString(4, b.title); p.setString(5, b.shortTitle); p.setString(6, b.abbr); p.setInt(7, b.chapters)
                p.setInt(8, if (b.deuterocanonical) 1 else 0); p.addBatch()
            }
            p.executeBatch()
        }
        val pv = c.prepareStatement("INSERT INTO verse VALUES(?,?,?,?,?)")
        val pf = c.prepareStatement("INSERT INTO verse_fts(docid, stem) VALUES(?,?)")
        for (b in books) for (v in verses[b.id].orEmpty()) {
            val id = verseId(b.id, v.chapter, v.verse)
            pv.setInt(1, id); pv.setInt(2, b.id); pv.setInt(3, v.chapter); pv.setInt(4, v.verse); pv.setString(5, v.text); pv.addBatch()
            pf.setInt(1, id); pf.setString(2, TextNormalizer.stems(v.text)); pf.addBatch()
        }
        pv.executeBatch(); pf.executeBatch(); pv.close(); pf.close()
        c.createStatement().use { s ->
            s.executeUpdate("INSERT INTO verse_fts(verse_fts) VALUES('optimize')")
            s.executeUpdate("PRAGMA user_version = $DB_VERSION")
        }
        c.commit()
    }
    DriverManager.getConnection("jdbc:sqlite:${out.path}").use { c -> c.createStatement().use { it.executeUpdate("VACUUM") } }
}

package bible.app.domain

import bible.app.data.Book
import bible.app.data.ChapterRef
import bible.app.data.ReadingPosition

class ChapterNavigator(private val books: List<Book>) {
    private val startIndex: Map<Int, Int>
    private val refs: List<ChapterRef>

    init {
        val list = ArrayList<ChapterRef>()
        val starts = HashMap<Int, Int>()
        for (b in books) {
            starts[b.id] = list.size
            for (c in 1..b.chapters) list += ChapterRef(b.id, c)
        }
        refs = list
        startIndex = starts
    }

    val totalChapters: Int get() = refs.size

    fun indexOf(ref: ChapterRef): Int = startIndex.getValue(ref.bookId) + ref.chapter - 1
    fun refAt(index: Int): ChapterRef = refs[index]
    fun next(ref: ChapterRef): ChapterRef? = refs.getOrNull(indexOf(ref) + 1)
    fun previous(ref: ChapterRef): ChapterRef? = refs.getOrNull(indexOf(ref) - 1)

    fun sanitize(pos: ReadingPosition): ReadingPosition {
        val book = books.firstOrNull { it.id == pos.ref.bookId } ?: return ReadingPosition(refs.first(), 1)
        if (pos.ref.chapter !in 1..book.chapters) return ReadingPosition(ChapterRef(book.id, 1), 1)
        return pos.copy(verse = pos.verse.coerceAtLeast(1))
    }
}

package bible.app.data

import java.io.File
import java.io.InputStream

class InstallFailed(cause: Throwable) : Exception(cause)

class AssetInstaller(
    private val open: () -> InputStream,
    private val target: File,
    private val version: Int,
) {
    private val marker = File(target.parentFile, target.name + ".version")

    fun install(): File {
        if (target.exists() && marker.exists() && marker.readText() == version.toString()) return target
        val tmp = File(target.parentFile, target.name + ".tmp")
        try {
            target.parentFile?.mkdirs()
            open().use { input -> tmp.outputStream().use { input.copyTo(it, 64 * 1024) } }
            target.delete()
            marker.delete()
            if (!tmp.renameTo(target)) throw java.io.IOException("rename failed")
            marker.writeText(version.toString())
            return target
        } catch (e: Throwable) {
            tmp.delete()
            if (!marker.exists()) target.delete()
            throw InstallFailed(e)
        }
    }
}

package bible.app.data

import android.content.Context
import androidx.datastore.preferences.core.edit
import androidx.datastore.preferences.core.intPreferencesKey
import androidx.datastore.preferences.preferencesDataStore
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.map

private val Context.dataStore by preferencesDataStore("reading")

class ReadingStore(private val context: Context) {
    private val book = intPreferencesKey("book")
    private val chapter = intPreferencesKey("chapter")
    private val verse = intPreferencesKey("verse")
    private val size = intPreferencesKey("text_size")
    private val spacing = intPreferencesKey("line_spacing")

    val position: Flow<ReadingPosition?> = context.dataStore.data.map { p ->
        val b = p[book] ?: return@map null
        ReadingPosition(ChapterRef(b, p[chapter] ?: 1), p[verse] ?: 1)
    }

        context.dataStore.edit { it[book] = pos.ref.bookId; it[chapter] = pos.ref.chapter; it[verse] = pos.verse }

    suspend fun setLineSpacing(step: Int) { context.dataStore.edit { it[spacing] = step.coerceIn(0, 2) } }

package bible.app.ui.art

import android.annotation.SuppressLint
import android.content.Context
import androidx.annotation.DrawableRes
import bible.app.R
import bible.app.data.Book
import bible.app.data.BookGroup

@DrawableRes
fun artForGroup(group: BookGroup): Int = when (group) {
    BookGroup.LAW -> R.drawable.art_group_law
    BookGroup.HISTORY -> R.drawable.art_group_history
    BookGroup.WISDOM -> R.drawable.art_group_wisdom
    BookGroup.PROPHETS -> R.drawable.art_group_prophets
    BookGroup.HISTORY_LATE -> R.drawable.art_group_history_late
    BookGroup.GOSPELS -> R.drawable.art_group_gospels
    BookGroup.ACTS -> R.drawable.art_group_acts
    BookGroup.CATHOLIC_EPISTLES -> R.drawable.art_group_catholic_epistles
    BookGroup.PAUL -> R.drawable.art_group_paul
    BookGroup.REVELATION -> R.drawable.art_group_revelation
}

private val bookArtCache = HashMap<Int, Int>()

@SuppressLint("DiscouragedApi")
@DrawableRes
fun artFor(context: Context, book: Book): Int = bookArtCache.getOrPut(book.id) {
    context.resources.getIdentifier("art_book_${book.id}", "drawable", context.packageName)
        .takeIf { it != 0 } ?: artForGroup(book.group)
}

val homeCarouselArts: List<Int> = listOf(
    R.drawable.art_group_gospels,
    R.drawable.art_group_law,
    R.drawable.art_group_wisdom,
    R.drawable.art_group_acts,
    R.drawable.art_group_prophets,
)

sealed interface LoadState {
    data object Loading : LoadState
    data class Ready(val db: BibleDatabase) : LoadState
    data object NoSpace : LoadState
}

object Routes {
    const val HOME = "home"
    const val BIBLE = "bible"
    const val TOC = "toc"
}

@Composable
fun AppRoot(container: AppContainer) {
    var attempt by remember { mutableIntStateOf(0) }
    var state by remember { mutableStateOf<LoadState>(LoadState.Loading) }
    LaunchedEffect(attempt) {
        state = try { LoadState.Ready(container.database()) } catch (e: InstallFailed) { LoadState.NoSpace }
    }
    when (val s = state) {
        LoadState.Loading -> Box(Modifier.fillMaxSize())
        LoadState.NoSpace -> NoSpaceScreen { state = LoadState.Loading; attempt++ }
        is LoadState.Ready -> Tabs(container, s.db)
    }
}

@Composable
private fun NoSpaceScreen(onRetry: () -> Unit) {
    Column(
        Modifier.fillMaxSize().padding(32.dp).testTag("screen-no-space"),
        verticalArrangement = Arrangement.spacedBy(16.dp, Alignment.CenterVertically),
        horizontalAlignment = Alignment.CenterHorizontally,
    ) {
        Text("Недостаточно памяти для установки текста Библии: нужно ~15 МБ. Освободите место и повторите.", textAlign = TextAlign.Center)
        Button(onClick = onRetry) { Text("Повторить") }
    }
}

@Composable
private fun Tabs(container: AppContainer, db: BibleDatabase) {
    val nav = rememberNavController()
    val entry by nav.currentBackStackEntryAsState()
    val route = entry?.destination?.route
    val bibleSelected = route == Routes.BIBLE || route == Routes.TOC
    Scaffold(
        containerColor = BibleColors.Background,
        bottomBar = {
            NavigationBar(containerColor = BibleColors.Background) {
                val colors = NavigationBarItemDefaults.colors(indicatorColor = BibleColors.Tab, selectedIconColor = BibleColors.Ink, selectedTextColor = BibleColors.Ink, unselectedIconColor = BibleColors.Muted, unselectedTextColor = BibleColors.Muted)
                NavigationBarItem(
                    selected = route == Routes.HOME,
                    onClick = { nav.navigate(Routes.HOME) { popUpTo(Routes.HOME) { inclusive = true }; launchSingleTop = true } },
                    icon = { Icon(painterResource(R.drawable.ic_home), null) },
                    label = { Text("Главная") },
                    colors = colors,
                )
                NavigationBarItem(
                    selected = bibleSelected,
                    onClick = { nav.navigate(Routes.BIBLE) { popUpTo(Routes.HOME); launchSingleTop = true } },
                    icon = { Icon(painterResource(R.drawable.ic_book), null) },
                    label = { Text("Библия") },
                    colors = colors,
                )
            }
        },
    ) { padding ->
        NavHost(nav, startDestination = Routes.HOME, modifier = Modifier.padding(bottom = padding.calculateBottomPadding())) {
            composable(Routes.HOME) { Text("home", Modifier.testTag("screen-home")) }
            composable(Routes.BIBLE) { Text("reader", Modifier.testTag("screen-reader")) }
            composable(Routes.TOC) { Text("toc", Modifier.testTag("screen-toc")) }
        }
    }
}
