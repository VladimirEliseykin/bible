# Объяснение стиха

Дата: 2026-10-26. Статус: экран утверждён владельцем; секции и источники утверждены (вторая редакция);
данные — пилот (Сирах 2, Матфей 5:1–12), затем вся книга Сираха и всё Евангелие от Матфея.

## Цель

Нажатие на любой стих открывает страницу, где он объяснён полно и так, чтобы его понял любой человек: смысл слов и связи
с другими местами Библии, обстановка, толкования святых отцов, что это значит для жизни, материалы для чтения.
Всё работает без интернета. В приложении нет ИИ: объяснения заранее подготовлены, проверены и лежат в базе.

## Что входит

1. Страница стиха (экран утверждён, макеты: `docs/mockups/page3.html` вариант 5, `docs/mockups/btnsD.html` вариант 1, `docs/mockups/verse-page.html`).
2. База объяснений `commentary.db` входит в приложение (решение владельца: «всё сразу в приложении, без дополнительного скачивания»). Сеть приложению не нужна.
3. Конвейер `tools/commentary`: корпус источников → объяснения по главам (JSON) → проверки → `commentary.db`.
4. Данные: вся книга Премудрости Иисуса, сына Сирахова (51 глава, 1523 стиха) и Евангелие от Матфея (28 глав, 1071 стих).
   Готовят агенты в сессии Claude Code по руководству `tools/commentary/GUIDE.md`; сначала пилот, после согласия владельца — остальное.
5. Плашка главы на экране чтения: название главы — золотой пилюлей.

## Что не входит

- Церковнославянский текст (решение владельца: занимает много места, не очень нужен) и вкладка «Переводы»: Синодальный текст и так в шапке.
- Современный перевод РБО — только после письменного разрешения правообладателя.
- Остальные книги Библии — отдельное решение владельца после Сираха и Матфея.
- «Спросить о стихе», ИИ в приложении.

## Экран «Стих»

Открывается нажатием на стих на экране чтения, выезжает справа. Нижние вкладки «Главная / Библия» на нём скрыты.

**Шапка** (растёт вниз, кнопки сверху никогда не перекрываются):
- акварель книги на всю ширину (с точкой интереса `ART_FOCUS_Y`);
- сверху стеклянные кнопки «‹ Сирах 2» (назад к главе) и «Поделиться»;
- плавающая плашка из тёмного матового стекла (Haze, Android 12+; ниже — непрозрачная `rgba(18,20,26,.72)`): на верхнем крае золотая пилюля «СИРАХ 2:1», ниже текст стиха по центру шрифтом Literata белым;
- под тонкой линией внутри плашки — подписи соседних стихов: слева «ПРЕДЫДУЩИЙ / ‹ 1:30», справа «СЛЕДУЮЩИЙ / 2:2 ›» (вариант D1). У первого стиха Библии нет левой подписи, у последнего — правой. Переход через границы глав и книг.

**«Кратко»** — кремовая полоса, заголовок «КРАТКО» золотом, текст курсивом по центру, орнамент «✦ ✦ ✦».

**Вкладки** — текст с золотым подчёркиванием активной, закреплены при прокрутке, листаются вбок, если не помещаются:
Смысл · Контекст · Толкования · Для жизни · Ссылки. Пустая вкладка не показывается; если пусты все — нет и полосы вкладок.

**Содержимое вкладок** — пункты с золотой точкой: заголовок с засечками, под ним текст; между пунктами тонкая линия.
- «Смысл» — разбор слов и фраз; под пунктом карточки мест Библии, о которых он говорит (цитаты Ветхого Завета,
  исполненные пророчества, то же событие в других Евангелиях, та же мысль в других книгах): место золотом, текст стиха,
  стрелка ›; нажатие открывает это место на экране чтения.
- «Контекст» — пункты стиха, затем общие для главы; трудные места — пунктами «Вопрос: …?».
- «Толкования» — дословная цитата, автор, сочинение и место в нём, «↗ Источник»; текст длиннее 3 строк свёрнут, «Читать полностью».
- «Для жизни» — 1–3 пункта по словам толкователей.
- «Ссылки» — карточки статей и материалов в интернете о стихе и о главе: сайт золотом, название, «↗»; открываются в браузере.

**Нижняя панель** — появляется, когда шапка уезжает при прокрутке: та же плашка, что на экране чтения (белая, 40 dp, скругление 20 dp, тень), стрелки «‹ ›» по краям, по центру золотая пилюля «СИРАХ 2:1».

**Жесты** — свайп влево/вправо листает стихи (по всей Библии); системная «Назад» возвращает к главе, на тот же стих.

**«Поделиться»** — системное меню Android, текст: «Сирах 2:1 – <стих>\n\nКратко: <кратко>».

**Без скачивания** — база в APK, при первом открытии стиха копируется во внутреннюю память (как `bible.db`, через `AssetInstaller`, один раз на сборку). Разрешения INTERNET у приложения нет; ссылки открывает браузер.

**Типографика** — в объяснениях только короткое тире «–» (в дословных цитатах — как в источнике). Текст Синодального перевода не меняется.

## Плашка главы на экране чтения

«‹ ЛЕВИТ 3 ›»: название главы — золотая пилюля (фон `#E9D3A0`, текст `#3B2C10`, прописные, разрядка 0.08em), остальное без изменений.

## Данные

`commentary.db` (SQLite, только чтение, лежит в APK, копируется во внутреннюю память):

```
meta(key TEXT PRIMARY KEY, value TEXT)                -- version, built_at
verse_note(verse_id INTEGER PRIMARY KEY, body BLOB)  -- deflate(JSON VerseNote)
chapter_note(book_id INTEGER, chapter INTEGER, body BLOB, PRIMARY KEY(book_id, chapter))
source(id TEXT PRIMARY KEY, title TEXT, author TEXT, url TEXT, license TEXT)
```

`VerseNote` (JSON), полное описание полей — `tools/commentary/GUIDE.md`:
```json
{
  "lead": "Кратко…",
  "meaning": [{"title": "«нищие духом»", "text": "…", "refs": [{"verse_id": 53006020}], "src": ["zlatoust_mf"]}],
  "context": [{"title": "Вопрос: …?", "text": "…", "src": ["lopukhin"]}],
  "fathers": [{"author": "Блж. Феофилакт Болгарский", "quote": "…", "source": "feofilakt_mf", "where": "…", "url": "https://…"}],
  "life": [{"title": "…", "text": "…", "src": ["zlatoust_mf"]}],
  "links": [{"title": "…", "url": "https://…", "site": "Азбука веры"}]
}
```
`ChapterNote` — `context` и `links`, общие для главы. `src` — id источников, на которых основан пункт (в приложении не показывается,
нужен для проверки). Текст мест Библии берётся из `bible.db`. Глава может лежать в нескольких файлах (`005-01.json`, `005-07.json`).

## Конвейер `tools/commentary`

Kotlin/JVM:
1. `fetchOptina` — толкования с bible.optina.ru по стихам в `corpus/<книга>/<глава>/<стих>.md` (в git не хранится);
   `savePage` — любая страница дословно в `corpus/…/extra/`, чтобы цитаты из неё проходили проверку.
2. Авторы (агенты) пишут `notes/<книга>/<глава>.json` по `GUIDE.md`: корпус + исследование в интернете.
3. `checkNotes` — структура (ниже) и дословность каждой цитаты по корпусу главы (без учёта пробелов, вида кавычек, тире, «ё»;
   «…» — пропуск); длина цитат по лицензии.
4. Сборка приложения (`generateCommentaryDb`) проверяет структуру и пишет `commentary.db` в assets. Проверки структуры:
   стихи и `refs` существуют в `bible.db`; у каждого пункта есть известные источники; ссылки — https с названием и сайтом;
   нет длинного тире «—» в своих текстах; «Кратко» не пусто и ≤ 300 знаков; нет пустых пунктов; стих не описан дважды.
5. Второй проход: отдельный агент-проверяющий сверяет главу с источниками (точность, полнота, пропуски) и правит.
   Владелец выборочно читает.

## Ошибки и края

- База повреждена: `AssetInstaller` проверяет её при открытии и копирует из APK заново.
- Нет объяснения для стиха: шапка и «Объяснение этого стиха ещё готовится», вкладок нет.
- Стих-ссылка указывает на несуществующее место, цитата не находится дословно — сборка или проверка падает.

## Тестирование

- Конвейер: проверки на некорректные данные (несуществующий стих или ссылка, длинное тире, пустой пункт, пункт без источника,
  ссылка не https, выдуманная цитата, фрагменты не по порядку, длинная цитата под авторским правом), разбор страниц bible.optina.ru.
- Приложение: загрузка базы из APK, переход к соседнему стиху через границы глав и книг, первый и последний стих Библии;
  UI-тесты страницы: вкладки, пустые вкладки скрыты, карточки мест в «Смысле» открывают чтение, нижняя панель появляется
  при прокрутке, кнопки шапки не перекрываются плашкой при самом длинном стихе и шрифте ×2.
