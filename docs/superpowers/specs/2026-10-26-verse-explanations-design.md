# Объяснение стиха

Дата: 2026-10-26. Статус: экран утверждён владельцем; данные — пилот на Сирахе 2.

## Цель

Нажатие на любой стих открывает страницу, где он объяснён так, чтобы его понял любой человек: смысл слов, обстановка, где ещё об этом в Библии, переводы, толкования. Всё работает без интернета. В приложении нет ИИ: объяснения заранее подготовлены, проверены и лежат в базе.

## Что входит

1. Страница стиха (экран утверждён, макеты: `docs/mockups/page3.html` вариант 5, `docs/mockups/btnsD.html` вариант 1, `docs/mockups/verse-page.html`).
2. Пакет объяснений `commentary.db`: скачивается одним файлом из приложения, дальше работает без сети.
3. Конвейер сборки пакета `tools/commentary`: JSON по главам → проверка → `commentary.db`.
4. Пилот данных: Сирах, глава 2 (18 стихов), подготовлен вручную по источникам.
5. Плашка главы на экране чтения: название главы — золотой пилюлей.

## Что не входит

- Полный прогон генерации на 77 книг через Claude API — отдельное решение владельца после пилота (стоит денег, см. «Полный прогон»).
- Современный перевод РБО — только после письменного разрешения правообладателя; модель данных его поддерживает.
- Греческий текст — после того как найдём проверенный общедоступный машинно-читаемый текст (Swete из OpenGreekAndLatin — нераспознанный OCR, не годится).
- «Спросить о стихе», ИИ в приложении.

## Экран «Стих»

Открывается нажатием на стих на экране чтения, выезжает справа. Нижние вкладки «Главная / Библия» на нём скрыты.

**Шапка** (растёт вниз, кнопки сверху никогда не перекрываются):
- акварель книги на всю ширину (с точкой интереса `ART_FOCUS_Y`);
- сверху стеклянные кнопки «‹ Сирах 2» (назад к главе) и «Поделиться»;
- плавающая плашка из тёмного матового стекла (Haze, Android 12+; ниже — непрозрачная `rgba(18,20,26,.72)`): на верхнем крае золотая пилюля «СИРАХ 2:1», ниже текст стиха по центру шрифтом Literata белым;
- под тонкой линией внутри плашки — подписи соседних стихов: слева «ПРЕДЫДУЩИЙ / ‹ 1:30», справа «СЛЕДУЮЩИЙ / 2:2 ›» (вариант D1). У первого стиха Библии нет левой подписи, у последнего — правой. Переход через границы глав и книг.

**«Кратко»** — кремовая полоса, заголовок «КРАТКО» золотом, текст курсивом по центру, орнамент «✦ ✦ ✦».

**Вкладки** — текст с золотым подчёркиванием активной, закреплены при прокрутке: Смысл · Контекст · Ссылки · Переводы · Отцы. Пустая вкладка не показывается.

**Содержимое вкладок** — пункты с золотой точкой: заголовок с засечками, под ним текст; между пунктами тонкая линия.
- «Ссылки» — карточки (место крупно золотом, текст стиха с засечками, стрелка ›); нажатие открывает это место на экране чтения.
- «Переводы» — Синодальный (из `bible.db`), церковнославянский (Елизаветинская Библия, оригинальная орфография, шрифт Ponomar Unicode, OFL).
- «Отцы» — цитата, автор, ссылка на источник; текст длиннее 3 строк свёрнут, «Читать полностью».

**Нижняя панель** — появляется, когда шапка уезжает при прокрутке: та же плашка, что на экране чтения (белая, 40 dp, скругление 20 dp, тень), стрелки «‹ ›» по краям, по центру золотая пилюля «СИРАХ 2:1».

**Жесты** — свайп влево/вправо листает стихи (по всей Библии); системная «Назад» возвращает к главе, на тот же стих.

**«Поделиться»** — системное меню Android, текст: «Сирах 2:1 — <стих>\n\nКратко: <кратко>».

**Пакет не скачан** — на странице есть шапка, стих и «Переводы» (Синодальный); вместо остального карточка «Объяснения стихов · ≈ N МБ · Скачать». Прогресс, ошибки: нет сети («Нет подключения к интернету»), нет места («Недостаточно памяти: нужно ≈ N МБ»), повреждённый файл (контрольная сумма) — «Повторить».

**Типографика** — в объяснениях только короткое тире «–». Текст Синодального перевода не меняется.

## Плашка главы на экране чтения

«‹ ЛЕВИТ 3 ›»: название главы — золотая пилюля (фон `#E9D3A0`, текст `#3B2C10`, прописные, разрядка 0.08em), остальное без изменений.

## Данные

`commentary.db` (SQLite, только чтение, скачивается во внутреннюю память):

```
meta(key TEXT PRIMARY KEY, value TEXT)                -- version, built_at, sources
verse_note(verse_id INTEGER PRIMARY KEY, body BLOB)  -- deflate(JSON VerseNote)
chapter_note(book_id INTEGER, chapter INTEGER, body BLOB, PRIMARY KEY(book_id, chapter))
translation(verse_id INTEGER, code TEXT, text TEXT, PRIMARY KEY(verse_id, code))
source(id TEXT PRIMARY KEY, title TEXT, author TEXT, url TEXT, license TEXT)
```

`VerseNote` (JSON):
```json
{
  "lead": "Кратко…",
  "meaning": [{"title": "«искушение»", "text": "…"}],
  "context": [{"title": "Кто и когда", "text": "…"}],
  "refs": [{"verse_id": 56001002, "to": 56001003}],
  "fathers": [{"author": "А. П. Лопухин, Толковая Библия", "quote": "…", "source": "lopukhin"}]
}
```
`chapter_note` хранит пункты «Контекст», общие для главы; страница показывает пункты стиха, а если их нет — главы. Текст ссылок берётся из `bible.db`. Коды переводов: `csl` (церковнославянский); `rbo` и `grc` зарезервированы.

**Хостинг пакета** — GitHub Releases публичного репозитория, файл `commentary-v<N>.db.gz` и `commentary-v<N>.json` (версия, размер, sha256). Адрес манифеста — константа в приложении. Новая версия пакета предлагается к обновлению, старая продолжает работать.

## Источники

| Что | Источник | Лицензия |
|---|---|---|
| Синодальный | `bible.db` (bibleonline/rst) | общественное достояние |
| Церковнославянский | Елизаветинская Библия, `asdf-a11/ChurchSlavonicBibleInUtf8`, `CSlElizabeth-CS.json` | общественное достояние (1751/1757) |
| Толкования | А. П. Лопухин, «Толковая Библия» (1904–1913), Азбука веры; святые отцы в дореволюционных переводах | общественное достояние |
| Ссылки, «Кратко», «Смысл», «Контекст» | составляются по этим источникам, каждая ссылка проверяется по `bible.db` | — |

Современные статьи Азбуки веры и переводы под авторским правом — только ссылками.

## Конвейер `tools/commentary`

Kotlin/JVM, как `tools/dbgen`:
1. Вход: `tools/commentary/notes/<abbr>/<глава>.json` — объяснения по стихам и главе; `tools/commentary/sources/` — общедоступные тексты (CS JSON).
2. Проверки (сборка падает при ошибке): все `verse_id` и `refs` существуют в `bible.db`; цитаты отцов не пустые и у каждой есть известный `source`; в текстах объяснений нет длинного тире «—»; длина «Кратко» ≤ 300 знаков; нет пустых пунктов.
3. Выход: `commentary.db` + `.gz` + манифест с sha256 и размером.

## Полный прогон (не в этом плане)

Объяснения для остальных глав готовит Claude (Opus 5.5, Batch API) по пакету источников на главу; результат проходит те же проверки, владелец выборочно читает. Оценка ≈ $300–600 за всю Библию; перед запуском — замер на 5 главах и согласие владельца.

## Ошибки и края

- Пакет повреждён/неполный: не открывается, предлагается скачать снова (та же логика, что `AssetInstaller`: временный файл, sha256, затем переименование).
- Нет объяснения для стиха (пакет есть, стиха нет): видны «Переводы», вместо остального — «Объяснение этого стиха ещё готовится».
- Стих-ссылка указывает на несуществующее место: такой пункт не попадает в пакет (ловит проверка сборки).

## Тестирование

- Конвейер: проверки на некорректные данные (несуществующий стих, длинное тире, пустой пункт), сборка пилота.
- Приложение: загрузка/разбор `VerseNote`, переход к соседнему стиху через границы глав и книг, первый и последний стих Библии, состояние «пакет не скачан», скачивание с ошибками (нет места, неверная sha256) — на подменённом источнике данных; UI-тесты страницы: вкладки, пустые вкладки скрыты, нижняя панель появляется при прокрутке, кнопки шапки не перекрываются плашкой при самом длинном стихе и шрифте ×2.
